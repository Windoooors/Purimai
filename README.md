# Purimai

### Introduction
A maimai simulator dedicated to recreating the old time glory of maimai FiNALE, supporting 3simai.  
This project is still under construction.

### Supported Platforms
- Android
- iOS

#### Gettings Started
1. Launch the game.
2. Put 3simai chart folders into /sdcard/Android/data/com.Setchin.Purimai/files/Charts on Android or Purimai/Charts on iOS.
3. Launch the game again and enjoy.
